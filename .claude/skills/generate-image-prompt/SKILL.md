# 生成文生图 Prompt Skill

## 用途

当用户想要根据文章内容生成文生图 prompt 时使用。用户可能会说：
- "生成图片 prompt [article-name]"
- "帮我生成 [article-name] 的配图描述"
- "/generate-image-prompt [article-name]"
- "为这篇文章生成一张图"

## 前置条件

在执行此 skill 之前，应确保：
- 课文目录 `src/components/[article-name]/` 已存在
- 课文内容 `src/components/[article-name]/content.md` 已存在

如果缺少 content.md，提示用户先手动创建目录并放入课文内容。

## 工作流程

### Step 1. 确定课文名称

1. 从用户消息中解析 article-name
2. 如果未提供，使用 Glob 搜索 `src/components/*/content.md` 列出可用课文
3. 向用户展示列表，让用户选择

### Step 2. 询问图片尺寸

使用 AskUserQuestion 询问用户需要哪种尺寸：

| 选项 | 尺寸 | 用途 |
|------|------|------|
| 小图 | 430×630 | 封面图、卡片配图、竖版展示 |
| 大图 | 1980×650 | 横幅背景、页面头图、宽屏展示 |

根据选择的尺寸，后续的构图策略会有所不同：
- **小图 (430×630)**：竖幅，适合聚焦人物或单一场景
- **大图 (1980×650)**：超宽横幅，适合叙事流动、全景展开

### Step 3. 读取源文件

读取以下文件：
1. `src/components/[article-name]/content.md` - 课文原始内容
2. `src/components/[article-name]/design.md` - 设计文档（如果存在，作为参考）

### Step 4. 文本解构

对课文内容进行深度分析：

#### 4.1 提取叙事骨架

识别文章的核心叙事线：
- 时间线：事件的先后顺序
- 空间线：场景的转换流动
- 情感线：情绪的起伏变化

输出格式：
```
| 阶段 | 原文关键句 | 视觉转化建议 |
|------|-----------|-------------|
| 开端 | "..." | ... |
| 发展 | "..." | ... |
| 高潮 | "..." | ... |
```

#### 4.2 识别核心意象

从原文中提取具象的视觉元素：
- **人物**：谁在画面中？姿态、服饰、表情
- **场景**：在哪里？环境特征
- **物件**：有什么关键道具？
- **自然元素**：天气、季节、植物、动物

#### 4.3 捕捉情感基调

分析文章的情感底色：
- 主导情绪（欢快/忧郁/壮阔/静谧...）
- 氛围关键词（梦幻/现实/古朴/现代...）
- 情感张力（对比、冲突、和谐...）

### Step 5. 风格定位

#### 5.1 匹配艺术风格

根据文本类型和情感推导合适的艺术风格：

| 文本类型 | 情感特征 | 推荐风格 |
|---------|---------|---------|
| 古典诗词/文言文 | 隐逸、空灵 | 中国水墨山水 |
| 古典诗词/文言文 | 华丽、繁盛 | 工笔重彩 |
| 现代诗歌 | 朦胧、意象 | 印象派/表现主义 |
| 现代散文 | 写实、细腻 | 写实插画 |
| 外国文学 | 西方古典 | 油画风格 |
| 科幻/奇幻 | 未来、奇异 | 概念艺术/赛博朋克 |
| 童话/寓言 | 童趣、奇幻 | 童书插画/扁平风格 |

#### 5.2 确定色彩基调

- 主色调（1-2个核心色）
- 辅助色（2-3个点缀色）
- 整体明度（明亮/中性/暗沉）
- 对比策略（如：水墨灰调 vs 桃花粉红）

#### 5.3 定义整体氛围

用 3-5 个形容词概括画面氛围，如：
- "梦幻、空灵、古朴、宁静"
- "热烈、奔放、色彩斑斓"

### Step 6. 空间构图

根据 Step 2 选择的尺寸，采用不同的构图策略：

#### 小图 (430×630) 构图策略

竖幅构图，适合：
- **聚焦式**：人物或单一主体居中
- **纵深式**：从下到上展开场景
- **分层式**：上中下三段式布局

```
┌─────────────┐
│   远景/天空  │
│             │
├─────────────┤
│             │
│   主体场景   │
│             │
├─────────────┤
│   前景细节   │
└─────────────┘
```

#### 大图 (1980×650) 构图策略

超宽横幅，适合：
- **叙事流动**：从左到右或从右到左展开故事
- **全景展开**：横向展示完整场景
- **对比式**：左右两侧形成视觉对比

```
┌─────────────────────────────────────────────────────┐
│ 前景/起点  →  过渡区域  →  中心场景  →  背景/终点    │
└─────────────────────────────────────────────────────┘
```

#### 视觉引导线

选择合适的引导元素：
- 河流/道路/小径
- 光线/视线方向
- 色彩渐变
- 元素排列

### Step 7. 元素布局

#### 7.1 主体位置

确定画面主体的位置：
- 黄金分割点
- 中心聚焦
- 边缘留白

#### 7.2 氛围元素

添加增强氛围的元素：
- 光影效果
- 云雾/烟尘
- 天气表现

#### 7.3 细节点缀

丰富画面的细节元素：
- 动物（鸟、蝶、鸡犬...）
- 植物细节（落花、草叶...）
- 人文细节（炊烟、灯火...）

### Step 8. 技法指定

#### 8.1 具体画法

根据选定的艺术风格指定技法：
- 水墨：晕染、留白、皴法、点染
- 油画：厚涂、薄罩、笔触肌理
- 插画：线条风格、填色方式

#### 8.2 边缘处理

- **硬边**：清晰边界，适合写实风格
- **渐隐**：边缘溶解，适合梦幻氛围
- **装饰边框**：传统纹样框边

#### 8.3 特殊效果

- 纸张/画布纹理
- 光效（光晕、丁达尔效应...）
- 时间感（做旧、斑驳...）

### Step 9. 生成 Prompt

将以上分析整合为结构化的文生图 prompt：

```markdown
# [课文标题] 文生图 Prompt

## 分析过程

### 文本解构
[Step 4 的分析结果]

### 风格定位
[Step 5 的分析结果]

### 构图设计
[Step 6 的分析结果]

---

## 最终 Prompt

### 主题风格
[艺术风格定义，整体氛围描述]

### 构图布局
[构图方向，从哪到哪的叙事/视觉流动]

#### 前景
[前景元素描述]

#### 中景
[中景元素描述]

#### 背景/远景
[背景元素描述]

### 艺术技法
- 色彩：[色彩方案]
- 技法：[具体画法]
- 边缘：[边缘处理方式]
- 特效：[特殊效果]

### 文字（可选）
[如需题字：内容、位置、字体大小]

### 技术参数
- 尺寸：[430×630 或 1980×650]
```

### Step 10. 用户确认

1. 向用户展示完整的分析过程和生成的 prompt
2. 询问是否需要调整：
   - 风格偏好
   - 构图细节
   - 元素增减
3. 根据反馈修改后再次展示

### Step 11. 保存并完成

1. 将最终 prompt 保存到 `src/components/[article-name]/image-prompt.md`
2. 向用户确认保存位置
3. 提示用户可以将 prompt 用于各类文生图工具（Midjourney、DALL-E、Stable Diffusion 等）

## 尺寸说明

本项目固定使用两种尺寸：

| 尺寸 | 比例 | 用途 | 构图特点 |
|------|------|------|---------|
| **430×630** | 约 2:3 | 封面图、卡片 | 竖幅，聚焦单一场景或人物 |
| **1980×650** | 约 3:1 | 横幅背景 | 超宽横幅，叙事流动、全景展开 |

## 风格参考库

### 中国传统风格

| 风格 | 适用场景 | 关键词 |
|------|---------|-------|
| 水墨山水 | 山水诗、隐逸文 | 墨色浓淡、留白、意境、空灵 |
| 工笔花鸟 | 咏物诗、细腻描写 | 精细勾勒、设色典雅、写实 |
| 青绿山水 | 华丽、盛世 | 石青石绿、金碧辉煌 |
| 文人画 | 抒情、写意 | 简约、诗书画印一体 |

### 西方传统风格

| 风格 | 适用场景 | 关键词 |
|------|---------|-------|
| 印象派 | 光影、瞬间 | 色彩斑斓、笔触可见、光感 |
| 浪漫主义 | 情感强烈、壮阔 | 戏剧性光影、宏大场面 |
| 写实主义 | 叙事、细节 | 真实质感、细节丰富 |

### 现代风格

| 风格 | 适用场景 | 关键词 |
|------|---------|-------|
| 扁平插画 | 简洁、现代 | 几何形状、纯色块、简约 |
| 概念艺术 | 科幻、奇幻 | 宏大场景、想象力、细节丰富 |
| 动漫风格 | 青春、活力 | 大眼睛、鲜艳色彩、动感 |

## 注意事项

- 分析过程要充分展示推理逻辑，让用户理解"为什么这样设计"
- 风格选择要从内容本身提取灵感，不要机械套用
- 优先使用原文中的意象，而非凭空添加元素
- prompt 要具体、可执行，避免模糊描述
- 如有不确定，使用 AskUserQuestion 询问用户偏好
- 保持灵活性，不同文章可能需要完全不同的处理方式

## 示例

### 输入

《桃花源记》原文，选择大图 (1980×650)

### 输出（简化版）

**分析过程：**
- 叙事骨架：寻径 → 过渡 → 发现
- 核心意象：渔人、小船、桃花林、山洞、村舍、鸡犬
- 情感基调：梦幻、隐逸、世外桃源

**风格定位：**
- 艺术风格：中国传统水墨山水画
- 色彩：墨色为主，桃花处粉色/朱砂点染
- 氛围：梦幻、空灵、古朴

**最终 Prompt：**
```
主题风格:
中国传统水墨山水画，表现《桃花源记》的叙事意境。
整体氛围：梦幻、空灵、古朴。

构图 (横幅，从右下至左上):

前景 (右下):
一叶扁舟，渔夫撑篙，沿蜿蜒溪流逆行。
两岸墨色浓重的岩壁与密林。

中景 (中右):
溪流穿入山峦，山壁隐约一处小口透出微光。

背景 (左上):
豁然开朗的桃源：粉色桃花、散落茅舍、田畴、鸡犬。

远景: 淡墨云山。

技法:
- 墨色为主，仅桃花处用粉/朱砂
- 四周晕染留白，边缘自然消融
- 左上角题字"桃花源记"

尺寸: 1980×650
```
