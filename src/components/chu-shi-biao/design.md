# 出师表 Design Document (最终定稿：孤灯帐下)

## 1. 核心意境 (Core Concept)

### “寒夜孤灯，鞠躬尽瘁”
不在沙场，而在帐中。不是金戈铁马的喧嚣，而是**黎明前最深沉的寂静**。
一位从战火中走来的老臣，在出征前夜，面对孤灯，将毕生心血凝结于笔端。

**高级感的来源**：
- **克制 (Restraint)**：不直接画出诸葛亮的人物形象，而是通过“案台”、“摇曳的灯火”、“批注的地图”来侧写（Side-writing）人物。
- **光影 (Chiaroscuro)**：借鉴伦勃朗式用光。大部分画面隐于黑暗，只有核心的“奏折”和“墨迹”被暖光照亮，聚焦感极强。
- **材质 (Texture)**：粗糙的军帐布料 vs 细腻的丝绢奏折，形成质感对比。

## 2. 视觉设计 (Visual Design)

### 色彩系统
- **环境色**：**深邃夜蓝** (`#0f172a`) —— 象征帐外的寒夜与无尽的忧虑。
- **光源色**：**摇曳暖金** (`#f59e0b` ~ `#d97706`) —— 象征仅存的希望与忠诚的火焰。
- **文字色**：**墨黑** (`#1a1a1a`) 在 **绢白** (`#f3f4f6`) 底色上，或者**反白**在深色背景中（视具体段落沉浸感而定）。

### 字体排印
- **标题**：**榜书/行楷**。不仅要力道，还要有“墨落纸上”的晕染感。
- **正文**：高雅的**老宋体**（如 Source Han Serif 或 Noto Serif），字重适中，行距偏大（2.0），营造从容不迫的阅读节奏。

## 3. 页面结构与交互 (Structure & Interaction)

### Hero Section：帐中静思
- **画面**：全屏暗色。视口中央是一盏油灯（动态火苗），照亮了案台一角。案上放着展开的空白奏折，笔架上的毛笔似乎刚蘸满墨。
- **动态**：
    - 灯火随风微微摇曳，光影在桌面上投下动态的影子（使用 CSS Radial Gradient 动画或 Canvas）。
    - 帐篷外传来隐约的风声（视觉化：帐篷布料的轻微起伏）。
- **标题显现**：墨迹在虚空中晕染开，汇聚成“出师表”三个大字。

### Content Section：灯下漫笔
- **隐喻**：屏幕就是那张奏折。用户的滚动，就是在**书写/回顾**这篇表文。
- **光随文动 (Spotlight Reading)**：
    - 这是一个关键的高级交互。**光源并不固定**，而是随着用户的阅读位置（滚动条）移动。
    - 用户读到哪里，光就照亮哪里。周围是半暗的，营造极强的**专注感**和**私密感**。

### 关键节点交互 (Key Moments)

1.  **回顾先帝 (Reflecting on the Past)**
    - 当读到“先帝创业未半...”时，光圈边缘隐约浮现出**残破的汉代地图**纹理，仿佛是透过纸背看到了过去的辉煌与遗憾。

2.  **五月渡泸 (The Southern Campaign)**
    - 读到“五月渡泸，深入不毛”时，灯火变得**更加红热**，且有微微的**烟雾/瘴气**在光圈周围缭绕（WebGL/粒子特效）。

3.  **临表涕零 (The Emotional Climax)**
    - 结尾处，光线逐渐微弱，仿佛油尽灯枯。
    - 或者是**泪滴**效果：画面出现轻微的水波纹扭曲，模糊了文字，直观传达“涕零”的感受。

## 4. 素材需求 (Assets)

1.  **`lamp-flame.json` / `component`**: 高质量的火焰动画（Lottie 或 CSS 关键帧）。
2.  **`tent-texture.png`**: 带有布料纹理的深色背景图。
3.  **`scroll-paper.jpg`**: 细腻的宣纸/丝绢纹理，带有轻微的做旧感。
4.  **`ink-spread.mp4` / `sprite`**: 墨水晕染的遮罩素材。

## 5. 技术实现 (Tech Stack)

- **光影引擎**：使用 CSS `radial-gradient` 配合 `requestAnimationFrame` 动态改变光圈位置 (`background-position`)，模拟“光随文动”。
- **文字显现**：`Framer Motion` 的 `staggerChildren`，让文字逐行或逐段优雅浮现。
- **粒子系统**：用于模拟灯花爆裂或微尘。

---

**设计总结**：去掉了具象的战旗和复杂的战场，回归到**人**本身。用一盏孤灯，照亮一位老人最赤诚的内心。这是最高级的悲壮。
