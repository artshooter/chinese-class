# 设计文档 - 蜀道难

## 1. 内容理解

### 诗歌本质
李白的巅峰之作，是"诗仙"最狂放不羁的一曲。全诗以"蜀道之难，难于上青天"为核心，反复咏叹，气势磅礴。

### 三段结构
1. **第一段**：从开国神话到地理险峻，讲述蜀道从无到有的历史。黄鹤难飞，猿猱愁攀——自然之险。
2. **第二段**：从个人情感到视听冲击，悲鸟号、子规啼、飞湍喧——感官轰炸。
3. **第三段**：从剑阁天险到战争隐喻，一夫当关、狼与豺——人祸之忧。

### 核心情绪
- **震撼与敬畏**：不是恐惧，而是面对自然伟力时的惊叹
- **狂放与豪迈**：李白的"噫吁嚱"是文学史上最嚣张的开场
- **警示与深意**：表面写山川，实则暗藏政治隐喻

## 2. 设计直觉

### 第一印象
- **色彩**：**深邃的山岩灰**与**金红的云霞**交织——险峻与壮美并存
- **质感**：粗粝、嶙峋、带有岩石的纹理感
- **动态**：垂直的、压迫的、令人仰望的

### 核心隐喻
"**攀登者的视角**"——读者化身旅人，逐步攀登这条天路，从凝望蜀道入口，到仰视栈道绝壁，再到站立剑阁之巅。

### 设计情绪板
```
噫吁嚱！     →  震惊开场，文字爆炸式呈现
危乎高哉！   →  垂直构图，压迫性的山峰剪影
蜀道难       →  三次重复如雷声回响
六龙回日     →  神话意象，太阳与龙的视觉元素
黄鹤/猿猱   →  空中俯瞰的高度感
悲鸟/子规   →  音效与视觉的通感设计
剑阁峥嵘     →  险关要塞的建筑感
```

## 3. 视觉设计

### 色彩系统

| 名称 | 色值 | 用途 |
|------|------|------|
| **蜀山墨** | `#1A1A2E` | 主背景色，夜色中的山峦 |
| **绝壁灰** | `#4A4A5A` | 岩石、山体的层次色 |
| **栈道棕** | `#8B4513` | 古栈道、木构建筑、强调文字 |
| **云霞金** | `#FFD93D` → `#FF6B35` | 太阳、高光、神话元素 |
| **雾青** | `#87CEEB` | 远山青泥、天空留白 |
| **月白** | `#F5F5F5` | 文字色、云雾 |

### 字体排印
- **开场咏叹**：极粗黑体/魏碑体，动态缩放，模拟"噫吁嚱"的爆发力
- **正文**：楷体风格的衬线体，行距 2.0，保持古典韵味
- **反复句**：加大字号，居中，如同回声环绕

## 4. 页面结构

### Hero Section：蜀山之门

- **画面**：垂直构图的蜀山剪影，群峰层叠，从底部延伸至画面顶端消失于云雾
- **动态**：
  - 云雾在山间缓缓流动（CSS animation）
  - 标题"蜀道难"从山间浮现，带有岩石质感
  - 远处山峰有微弱的光晕（六龙回日的暗示）
- **开场**："噫吁嚱，危乎高哉！"以爆发式动画呈现，字体从微小到巨大

### Content Section：攀登之途

#### 第一节：远古蜀道
- **布局**：垂直滚动，文字如同栈道般"架设"在山崖旁
- **视觉**：
  - 背景山势随滚动逐渐陡峭
  - "四万八千岁"——数字滚动动画，展示时间的漫长
  - "蚕丛及鱼凫"——简笔古蜀图腾剪影
- **高潮**："地崩山摧壮士死"——画面震颤效果

#### 分界：第一次咏叹
- **呈现**："蜀道之难，难于上青天！"
- **设计**：全屏居中，文字放大，背景短暂变暗后散开
- **音效建议**：雷鸣回响（可选）

#### 第二节：绝壁攀援
- **布局**：文字随滚动从侧边"攀"入画面
- **视觉**：
  - "上有六龙回日之高标"——太阳与盘龙的剪影动画
  - "下有冲波逆折之回川"——河流纹理在底部流动
  - 黄鹤与猿猱的剪影在画面中穿越
- **交互**：滚动时，视角如同在陡峭栈道上攀升
- **高潮**："扪参历井仰胁息"——屏幕微微倾斜，模拟仰望的眩晕

#### 第三节：空山鬼声
- **视觉**：画面色调转冷，由暖转青
- **元素**：
  - 悲鸟剪影绕林飞舞
  - "子规啼夜月"——月亮从云后显现，配以子规叫声波形动画
- **情绪**：压抑、凄凉，用留白和冷色调营造

#### 分界：第二次咏叹
- **呈现**："蜀道之难，难于上青天，使人听此凋朱颜！"
- **设计**：文字用栈道棕色强调，保持视觉的温雅与庄严

#### 第四节：险途惊雷
- **布局**：画面分割——上方绝壁枯松，下方飞瀑奔流
- **动态**：
  - "飞湍瀑流争喧豗"——瀑布动画，水流从画面顶端倾泻
  - "砯崖转石万壑雷"——屏幕震颤 + 滚石剪影
- **交互**：滚动过快时，画面模糊，暗示坠落的危险

#### 第五节：剑阁威慑
- **视觉**：
  - 剑阁关隘的古建筑剪影，占据画面中心
  - "一夫当关"——单人剪影守卫城门
  - "狼与豺"——隐约的兽影在暗处
- **色调**：以栈道棕与绝壁灰为主，营造肃穆与警戒的氛围
- **地图**：可选的锦城（成都）方位指示

#### 终章：回望咨嗟
- **最终画面**："侧身西望长咨嗟！"
- **视角**：旅人已过剑阁，回望来路
- **设计**：画面逐渐宽阔，色调转暖，露出锦城的远景
- **留白**：最后，只剩下远山轮廓与叹息般的风声

### 尾声：第三次咏叹（最终版）
- **呈现**："蜀道之难，难于上青天，侧身西望长咨嗟！"
- **设计**：文字悬浮于云海之上，背景渐隐为古宣纸色

## 5. 交互设计

### 核心交互：攀升滚动
- 滚动体验模拟攀登：向下滚动 = 向上攀升
- 速度感知：滚动越快，背景模糊越强，模拟"不可急于求进"
- 使用 `scroll-snap` 在关键节点（三次咏叹句）强制停留

### 微交互

| 元素 | 交互 | 效果 |
|------|------|------|
| 山体 | 滚动 | 视差移动，前景快、背景慢 |
| 咏叹句 | 进入视口 | 放大 + 回声扩散效果 |
| 栈道文字 | 滚动 | 随曲线路径显现 |
| 六龙/太阳 | Hover | 龙身微动，太阳光晕扩散 |
| 猿猱/黄鹤 | 进入视口 | 剪影飞过画面 |
| "朱颜"句 | 进入视口 | 渐变为红色 |

### 沉浸式音效（可选）
- 风声：始终存在，随高度变化强弱
- 水声：第四节瀑布段
- 鸟鸣：第三节空山段
- 雷声：咏叹句呈现时

## 6. 响应式设计

### 桌面端
- 全屏沉浸式体验，最大化视觉冲击
- 山体占满画面宽度，文字浮于山间
- 鼠标移动可微调视角（轻微的视差效果）

### 移动端
- 垂直滚动更适配攀登隐喻
- 减少粒子和动效，保证性能
- 触摸时产生"岩石纹理扩散"涟漪效果
- 咏叹句触发时设备振动（Haptic feedback）

## 7. 素材需求

1. **`hero-shu.webp`**：垂直构图的蜀山剪影，层峦叠嶂，云雾缭绕
2. **`cloud-mist.png`**：半透明云雾层，用于视差效果
3. **`icons/`**：极简线条图标
   - 蚕丛鱼凫图腾
   - 六龙回日（太阳+龙剪影）
   - 黄鹤/猿猱剪影
   - 悲鸟/子规剪影
   - 剑阁关隘
4. **`textures/`**：
   - 岩石纹理（用于文字背景）
   - 古栈道木纹
5. **可选音效**：风声、水声、子规啼叫、雷鸣

## 8. 技术实现

- **山体视差**：Framer Motion `useScroll` + `useTransform`，多层 z-index 控制
- **咏叹回声**：CSS `text-shadow` 动态扩散 + `@keyframes` 透明度变化
- **瀑布效果**：CSS `linear-gradient` + `animation` 流动，或 Canvas 粒子
- **震颤效果**：`motion.div` + `x: [0, -5, 5, -5, 0]` 快速抖动
- **攀升文字**：SVG `path` + `offsetPath` 让文字沿栈道曲线排列
- **视差层**：`position: sticky` + `transform: translateZ()` 3D 层

---

## 设计总结

> 《蜀道难》的核心在于**垂直感**——一切都在往上延伸，逼迫观者仰望。开场的"噫吁嚱"是文学史上最霸道的一击，设计应该匹配这种狂放。
> 
> 三次"蜀道之难"的反复，如同雷鸣回响于山谷，设计上用渐强的视觉效果呼应这种结构：第一次是宣告，第二次是哀叹，第三次是超然。
> 
> 最终，旅人（读者）完成攀登，站在剑阁之巅回望来路——此时应该感受到：**征服的成就感，与对来时险途的敬畏**。
